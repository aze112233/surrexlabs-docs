# Publishing to GitBook

This repository is GitBook-ready. To publish:

1. In GitBook, create/open a Space and connect it to this GitHub repository.
2. Set the sync branch to `main`.
3. GitBook will import `README.md`, `SUMMARY.md`, and the linked Markdown pages.

## Brand logo

Use [surrex-logo.png](assets/brand/surrex-logo.png) as the SURREX LABS logo. This is the original supplied `logoo.png`, preserved without image changes, and it is displayed on the welcome page.

For the published site's header logo, open the site's **Customization** tab and upload this asset in the logo setting. GitBook manages the site header through [site customization](https://gitbook.com/docs/publishing-documentation/customization/icons-colors-and-themes); adding an image to the welcome page does not configure that setting. Custom header logos require a Premium or Ultimate site plan.

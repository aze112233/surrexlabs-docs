# Publishing to GitBook

This folder is GitBook-ready. To publish:

1. Create or choose a GitHub/GitLab repository.
2. Push these files to the repository root.
3. In GitBook, create/open a Space and connect it to that repository.
4. Set the sync branch, usually `main`.
5. GitBook will import `README.md`, `SUMMARY.md`, and the linked Markdown pages.
